# Firebase Basics

This skill provides guidelines and reference patterns for initializing Firebase services, managing Firestore rules, and configuring client SDKs.

## Overview
- Project configuration via `app.json` or `GoogleService-Info.plist`
- Firestore database rules and offline persistence
- Client authentication state handling
